Animations

Animations have been moved into the main spike project. There are 5 global animation types: fade-in, fade-out, grid-collapse, grid-expand and skeleton. You only need to import the stylesheet.

Fade In/Out

Attach animate.enter/leave to any element
{{ 'animate.enter="fade-in"' }}
{{ 'animate.leave="fade-out"' }}

Grid Expand/Collapse

{{ gridSnippet }}

{{ 'animate.leave="grid-collapse"' }}
