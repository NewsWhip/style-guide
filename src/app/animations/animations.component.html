Animations

Animations have been moved into the main spike project. There are 5 global animation types: fade-in, fade-out, grid-collapse, grid-expand and skeleton. You only need to import the stylesheet.

Fade In

Attach animate.enter to any element

Fade Out

Attach animate.leave to any element

Grid Expand/Collapse

collapse-expand-grid-container class should be the outer wrapper
collapse-expand-grid-item class should be on the inner wrapper
