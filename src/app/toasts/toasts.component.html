    Live Example

    Description

    1. Character length

      Toast messages should ideally be limited to no more than 50 characters.

    2. Dismissal

      Successful toast messages should not be manually dismissable.

    3. Display time

      The default time to display the toast is 3 seconds.

    Accessibility

    1. Toasts announce themselves

      Do not pair a toast with a LiveAnnouncer.announce call for the same event — screen reader users will hear the message twice. A success toast is announced politely (role="status"), an error toast assertively (role="alert").

    2. Type is conveyed in text

      Each toast carries a visually hidden Success:/Error: prefix, so the type does not rely on icon colour alone. The prefix is included in the announcement.

    3. Message content

      The announcement is composed from the toast's rendered text, so a TemplateRef message and a message containing markup both announce correctly. Keep any meaning out of markup alone.
