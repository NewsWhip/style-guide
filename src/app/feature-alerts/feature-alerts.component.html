Feature Alerts

A service for highlighting new or updated features to users. Feature alerts persist their dismissed state in local storage, so they only appear once per user. Includes a structural directive for conditionally showing "New" badges and a hotspot component for drawing attention to specific UI elements.

Importing

Feature Alert Directive

This is a structural directive that can show / hide an element and store the state in local storage

Dismiss from button New

Hotspots

Directive Usage

Use the *nwFeatureAlert structural directive to conditionally show an element until it is dismissed.

Hotspot Usage

Add a pulsing hotspot indicator to draw attention to a specific element. The parent element must have position: relative.
