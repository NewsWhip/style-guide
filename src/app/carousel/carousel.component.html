API

Carousel Component

Selector nw-carousel
Exported as nw-carousel

Inputs

showPageIndicator boolean Optional Show the default page dot indicators or not. Defaults to true
showPagination boolean Optional Show the default previous and next buttons. Defaults to true
showMask boolean Optional Show a gradient when there are more items before / after the current page. Defaults to true
maskColor string Optional The color of the mask. Should match the carousel background for correct blending. Defaults to #ffffff
containerClass string Optional A class that is added to the .carousel element. Defaults to null

Carousel Slide Directive

Selector nwCarouselSlide
Exported as nw-carousel-slide

Inputs

snapAlign 'none' | 'start' | 'end' | 'center' Optional On paginating, the position to snap to. Defaults to start
